0.2.0 是 VectorFS 当前的预发布版本，文本模态是其 MVP。最简短的概括：文件放
进去，按语义搜出来，而同一个服务端还能直接对接未修改的 AWS SDK。

## 亮点 {#highlights}

- **两张经过验证的 API 面。** `s3vectors-2025-07-15` 的全部 21 个操作，错误
  与 AWS 逐字节兼容；外加 `/x-vf/` 下的 8 个原生操作。二者都由针对未修改
  boto3 与 aws-sdk-go-v2 的 32 步一致性套件证明。
- **面向文本的文件向量化。** PDF（pdfium 或纯 Rust 的 `pdf-inspector`）、
  Markdown 与纯文本，经 normalize → extract → chunk → embed 管线处理；token
  窗口分块对 CJK 安全。
- **三种预设。** 仅协议模拟器的 `dev`、带本地 gte-multilingual-base 模型
  （约 1.2 GiB）的 `text-rag`，以及面向离线安装的 `air-gapped`。
- **可插拔后端。** `file`、`memory` 与 `s3` —— 已在 SeaweedFS 4.52 与
  Cloudflare R2 上验证。索引以 Lance + JSON 的形式留在你的存储里。
- **Docker 与 MCP。** 多架构非 root 镜像、`emulator` compose profile，以及
  支持只读或读写工具集的 stdio MCP 服务器（`vectorfs mcp`、`vf mcp`）。

## 升级说明 {#upgrade-notes}

管线配置现在带指纹。如果自上次 `serve` 之后你改过解析器、分块器或嵌入器，
服务端会拒绝启动，直到传入 `--reindex` 或触发 `vf reindex`。

## 路线图 {#roadmap}

v0.3 的目标是图片模态、OCR、docx 与 HTML 解析，以及混合全文检索。
