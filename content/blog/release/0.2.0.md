Version 0.2.0 is the current pre-release of VectorFS, with the text modality as its MVP. The shortest summary: drop files in, search by meaning, and point unmodified AWS SDKs at the same server.

## Highlights {#highlights}

- **Two verified API faces.** All 21 operations of `s3vectors-2025-07-15` with AWS byte-compatible errors, plus 8 native operations under `/x-vf/`. Both proven by 32-step conformance suites against unmodified boto3 and aws-sdk-go-v2.
- **File vectorization for text.** PDF (pdfium or pure-Rust `pdf-inspector`), Markdown, and plain text through the normalize → extract → chunk → embed pipeline, with token-window chunking that is CJK-safe.
- **Three presets.** `dev` for protocol-only emulator use, `text-rag` with a local gte-multilingual-base model (≈1.2 GiB), and `air-gapped` for offline installs.
- **Pluggable backends.** `file`, `memory`, and `s3` — verified on SeaweedFS 4.52 and Cloudflare R2. Indexes stay Lance + JSON in your store.
- **Docker and MCP.** Multi-arch non-root images with an `emulator` compose profile, and stdio MCP servers (`vectorfs mcp`, `vf mcp`) with read-only or read-write tool sets.

## Upgrade notes {#upgrade-notes}

Pipeline configuration now carries a fingerprint. If you changed extractors, chunkers, or embedders since your last `serve`, the server will refuse to start until you pass `--reindex` or trigger `vf reindex`.

## Roadmap {#roadmap}

v0.3 targets the image modality, OCR, docx and HTML extraction, and hybrid full-text retrieval.
